# E010 — Абсолютный sources на другом диске Windows

[Errata](index.md) · [English](../../en/errata/E010.md)

**Статус:** open; исправление не входит в 0.10.1 по решению владельца.
**База:** 0.10.0 и main `6d066f0`. **Подтверждение:** reproduced, Windows,
CMake 3.21.7 / xPack GCC 14.2.1-1.1. Опция: `sources`.

Абсолютный каталог `C:/...` при проекте на D: превращается внутри обработки
sources в `<проект>/C:/...`. Каталог не подключается; Configure продолжается
с SCY-W302, а его исходник отсутствует в compile_commands.json.
Справочник описывает sources как относительные пути; обещание проверки другого
диска из TC-44 шире фактически проверенной поддержки. Не выдавать это за
работающую конфигурацию и не исправлять незаметно в тестовом задании.

Регрессия: windows-вариант baremetal-empty-list в tests/cases.json;
ci/run_windows_checks.py требует другой диск, точный W302 и отсутствие extra.c.
Проверяется через временную копию; пользовательские проекты не меняются.
Зелёный job означает воспроизведение ограничения, а не его исправление:
summary.json содержит tc44_complete=false, known_limitations=[E010].

Обход: разместить модуль на том же диске и задать поддерживаемый относительный
путь; автоматическое перемещение модулей не выполняется. ТЗ 4.6.1, 8.5.7, TC-44.
