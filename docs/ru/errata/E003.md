# E003: Только целочисленные размеры памяти

[Documentation](../index.md) → [Errata](index.md) → E003 · [English](../../en/errata/E003.md)

**Status:** Закрыто: ограничение по замыслу автора, не дефект.

Уточнено автором проекта 2026-09-22. Применимо к контракту 0.9.2; код не изменён.

Поддерживаются целые байты и целые числа с суффиксами K/M: `1536`, `1K`, `2M`.
`1.5K` не входит в контракт. Ошибка Configure на таком входе не является
дефектом поддержки дробей: эта поддержка не заявлялась.

Ранее запись ошибочно считала 1536 ожидаемым результатом для `1.5K`.
Диагностика исходного кода содержит пример `1.5K`, но он не определяет контракт
и противоречит уточнению автора. CMake math(EXPR) использует целочисленную арифметику.
Запись сохранена для истории ссылок; добавление дробных размеров не планируется.

Связанные опции: [heap_size](../reference/0.9.2/linker.md#heap-size),
[stack_size](../reference/0.9.2/linker.md#stack-size).
