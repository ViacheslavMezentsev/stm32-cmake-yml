# E002: list не читает внешний файл профилей

[Документация](../index.md) → [Errata](index.md) → E002 · [English](../../en/errata/E002.md)

**Статус:** Исправлено в 0.9.3: [PR #6](https://github.com/ViacheslavMezentsev/stm32-cmake-yml/pull/6) (`858013a`). **Baseline:** `0.9.2 @ f8ef5200fc7a4a96d6f3fe9111afb8f8825474b0`.

[`profiles_file`](../reference/0.9.2/profiles.md#profiles-file)

## Воспроизведение

Задать profiles_file: profiles.yml и вызвать cmake с -DSTM32_YML_PROFILE=list.

## Ожидание и фактическое поведение

Ожидается список из внешнего файла. В базе ветка list вызывается до его чтения и может сообщить, что профилей нет. Сам ненулевой код завершения list — штатное поведение, не этот дефект.

## Обход и совместимость

Посмотреть profiles.yml напрямую или временно разместить profiles в основном YAML.

## Подтверждение и исправление

Воспроизведено; регрессия `configure.external-list-profiles` слита вместе с исправлением.
