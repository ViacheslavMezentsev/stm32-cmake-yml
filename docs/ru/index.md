Карточки опций содержат назначение, тип, defaults, ограничения, ссылки на реализацию,
проверки и errata. Идентификаторы `CFG-*` и `E*` постоянны и одинаковы в обоих языках.
В GitHub пользуйтесь таблицами и поиском по странице; в VS Code — Markdown preview
и поиском имени опции. Отдельный сайт для навигации не требуется.
