# E003: Integer memory sizes only

[Documentation](../index.md) → [Errata](index.md) → E003 · [Русский](../../ru/errata/E003.md)

**Status:** Closed: by-design restriction, not a defect.

Clarified by the project author on 2026-09-22. Applies to the 0.9.2 contract; code is unchanged.

Supported inputs are integer bytes and integers with K/M suffixes: `1536`, `1K`, `2M`.
`1.5K` is outside the contract. Configure failing for this input is not a defect
in fractional-size support: such support was never promised.

This entry previously treated 1536 as the expected result for `1.5K` incorrectly.
The source diagnostic includes a `1.5K` example, but it does not define the
contract and conflicts with the author's clarification. CMake math(EXPR) uses
integer arithmetic. Keep this entry for stable links; fractional support is not planned.

Related options: [heap_size](../reference/0.9.2/linker.md#heap-size),
[stack_size](../reference/0.9.2/linker.md#stack-size).
