# E003: Fractional K/M sizes fail

[Documentation](../index.md) → [Errata](index.md) → E003 · [Русский](../../ru/errata/E003.md)

**Status:** Open. **Baseline:** `0.9.2 @ f8ef5200fc7a4a96d6f3fe9111afb8f8825474b0`.

[`heap_size`](../reference/0.9.2/linker.md#heap-size), [`stack_size`](../reference/0.9.2/linker.md#stack-size)

## Reproduction

With a local .ld.in set heap_size: 1.5K and run Configure.

## Expected and actual behavior

Comments/diagnostics advertise fractions. The expected equivalent is 1536 bytes. Actual CMake math(EXPR) cannot parse 1.5 * 1024, failing Configure.

## Workaround and compatibility

Use integer bytes (1536) or integer K/M. Baseline heap/stack suffixes are case-sensitive: K/M.

## Evidence and fix

Reproduced by local Configure with CMake 3.28.3 in the pinned Docker image. No permanent regression case yet.
