# E005: Profile naming restriction

[Documentation](../index.md) → [Errata](index.md) → E005 · [Русский](../../ru/errata/E005.md)

**Status:** Closed: by-design restriction, not a defect.

Clarified by the project author on 2026-09-22. Applies to the 0.9.2 contract; code is unchanged.

Underscores (`_`) are not allowed in profile names. Use names such as `boardRev`,
`G474` or `debug2`. Prefer ASCII letters and digits for predictable parsing and
avoid regex metacharacters.

The author confirmed this restriction, including possible Arduino build-path
issues. The previously reproduced listing truncation from `board_rev` to `board`
concerns an unsupported name and does not require a fix within the supported
contract. The specific Arduino issue has not been reproduced here.

This restriction applies to profile names, not all build paths/artifacts:
`arduino_core`, `arduino_custom_*` and YAML keys containing `_` are allowed.
Keep the entry for stable links; underscore support in profile names is not planned.
