# E005: Underscored profile names are truncated

[Documentation](../index.md) → [Errata](index.md) → E005 · [Русский](../../ru/errata/E005.md)

**Status:** Open. **Baseline:** `0.9.2 @ f8ef5200fc7a4a96d6f3fe9111afb8f8825474b0`.

[`profiles`](../reference/0.9.2/profiles.md#profiles)

## Reproduction

Declare profiles: {board_rev: {stack_size: 2K}} and request list.

## Expected and actual behavior

Expected board_rev. Actual output is board: the listing regex stops at the first underscore. This does not prove that selecting board_rev is impossible.

## Workaround and compatibility

Use names such as boardRev. Also avoid regex metacharacters: key selection interpolates names without escaping.

## Evidence and fix

Reproduced by parser/list calls during Configure. No permanent regression case yet.

[Source](https://github.com/ViacheslavMezentsev/stm32-cmake-yml/blob/f8ef5200fc7a4a96d6f3fe9111afb8f8825474b0/cmake/stm32_yml_profiles.cmake).

No verified fix or fixed version is recorded yet.
