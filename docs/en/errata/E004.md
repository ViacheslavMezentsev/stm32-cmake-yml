# E004: crc_algorithm does not select an algorithm

[Documentation](../index.md) → [Errata](index.md) → E004 · [Русский](../../ru/errata/E004.md)

**Status:** Open. **Baseline:** `0.9.2 @ f8ef5200fc7a4a96d6f3fe9111afb8f8825474b0`.

[`crc_algorithm`](../reference/0.9.2/postbuild.md#crc-algorithm)

## Reproduction

Enable CRC and change crc_algorithm to another name; compare the log and post-build command.

## Expected and actual behavior

Expected: select a supported algorithm or reject an unknown one. Actual: only the log changes; Python receives no algorithm argument and uses a fixed CRC.

## Workaround and compatibility

Use only STM32_HW_DEFAULT. Another algorithm needs matching computation and verification code; changing YAML is insufficient.

## Evidence and fix

Confirmed by the command in stm32_yml_postbuild.cmake and scripts/stm32_crc.py interface. Source-confirmed, not an alternate-CRC runtime test.

[Source](https://github.com/ViacheslavMezentsev/stm32-cmake-yml/blob/f8ef5200fc7a4a96d6f3fe9111afb8f8825474b0/cmake/stm32_yml_postbuild.cmake).

No verified fix or fixed version is recorded yet.
