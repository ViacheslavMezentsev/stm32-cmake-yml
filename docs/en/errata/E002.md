# E002: list does not read external profiles

[Documentation](../index.md) → [Errata](index.md) → E002 · [Русский](../../ru/errata/E002.md)

**Status:** Merged in [PR #6](https://github.com/ViacheslavMezentsev/stm32-cmake-yml/pull/6); release not established. **Baseline:** `0.9.2 @ f8ef5200fc7a4a96d6f3fe9111afb8f8825474b0`.

[`profiles_file`](../reference/0.9.2/profiles.md#profiles-file)

## Reproduction

Set profiles_file: profiles.yml and run cmake with -DSTM32_YML_PROFILE=list.

## Expected and actual behavior

Expected: names from the external file. Baseline calls list before loading it and can report no profiles. The nonzero list exit code itself is intentional, not this defect.

## Workaround and compatibility

Inspect profiles.yml directly or temporarily put profiles into the main YAML.

## Evidence and fix

Reproduced; regression `configure.external-list-profiles` was merged with the fix.
