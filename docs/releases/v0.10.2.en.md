## 0.10.2 — source paths and configuration

- Fixed absolute files and directories in `sources`, including spaces and another Windows drive (E010). Relative paths retain their behavior.
- Configuration reports use `[cfg]` instead of `[yml]` for YAML and TOML. Precedence, message codes and `STM32_YML_*` names are unchanged.
- Added a TOML + include + CMakePresets example: G474 base, separate F411/G474 profiles, independent paths and HAL lists, Debug/Release.
- Extended path, report and preset regressions; reconciled the RU/EN roadmap.

**Upgrade:** use `v0.10.2`, set `stm32_cmake_yml_version: 0.10.2` (TOML: `stm32_cmake_yml_version = "0.10.2"`), and configure from a clean build directory. Update scripts parsing the report text for the `[yml]` to `[cfg]` change.

**Scope:** the TOML example validates Configure/Generate, not complete firmware or HIL. The emulator matrix is unchanged; Arduino Core native remains tested with 2.12.0.
