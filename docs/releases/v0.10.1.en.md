## 0.10.1 — diagnostics and CRC verification

- Fixed UTF-8 CRC/BIN output on Windows. Localized CRC injection messages include the section name and failure reason.
- Added `crc_method: auto` (`none` remains an alias for `auto`). Documented the algorithm, length field and CRC placement; firmware checks length and zero residue in simulators.
- Diagnostics show each module's own Git SHA and `modified`; Windows short paths work correctly. Source markers `[yml]`, `[ioc]`, `[auto]` are aligned before values.
- Added Windows/Linux Host checks and native Windows Configure/Build; test failures are visible in Actions logs.

**Upgrade:** update the included module to `v0.10.1`, set `stm32_cmake_yml_version: 0.10.1`, and configure from a clean build directory. User linker-script layouts are not changed automatically; `crc_enable` still controls CRC activation.

**Limitations:** absolute `sources` on another Windows drive remain unsupported (E010, TC-44 partial). Simulators verify software CRC, not the hardware peripheral.
